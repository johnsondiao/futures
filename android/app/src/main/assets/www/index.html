飞书配置引导（点开查看详细步骤）

第 1 步：创建飞书自建应用

用手机或电脑浏览器打开 open.feishu.cn/app，登录飞书账号，点击「创建企业自建应用」，填应用名称（随意，比如"信号推送"）。

第 2 步：拿到 App ID 和 App Secret

应用创建后，在左侧菜单「凭证与基础信息」里可以看到 App ID（cli_ 开头）和 App Secret，复制后填到上方对应输入框。

第 3 步：启用机器人能力

左侧菜单「添加应用能力」→ 找到「机器人」→ 点击「添加」启用机器人能力。

第 4 步：配置权限（一键导入）

左侧「权限管理」→ 点击「批量导入/导出权限」→ 粘贴下方 JSON → 确认导入：

{
  "scopes": {
    "tenant": [
      "im:message:send_as_bot",
      "im:message",
      "im:message:readonly",
      "im:message.p2p_msg:readonly",
      "im:chat:readonly",
      "im:resource"
    ]
  }
}

第 5 步：配置事件订阅（长连接模式，关键步骤）

左侧「事件与回调」→「事件配置」→ 订阅方式选择「使用长连接接收事件」并保存。

然后点击「添加事件」→ 搜索 接收消息（im.message.receive_v1）→ 确认添加。

长连接模式无需公网 IP，App 会主动连接飞书网关；这也是只需填 App ID / App Secret 两个凭证的原因。

第 6 步：发布应用

左侧「版本管理与发布」→「创建版本」→ 填版本号（如 1.0.0）→ 提交审核 → 发布。
企业版飞书需要管理员审批；个人开发者版可直接发布。

第 7 步：绑定接收者（两种方式任选其一）

方式 A（推荐，不依赖事件订阅）：在手机飞书里打开机器人会话页（不用发消息），或建一个只有你和机器人的群；回到本页点「自动发现接收者」，App 会通过飞书 API 直接找到会话并绑定（需要 im:chat:readonly 权限）。

方式 B（事件自动配对）：在手机飞书里给机器人发一条任意消息，App 后台长连接收到消息事件后自动记住你的身份。

绑定成功后上方「接收者配对状态」变为已配对，机器人会发一条确认消息。

第 8 步：测试

回到本页，点「测试飞书推送」，手机飞书应该收到机器人私聊消息。

凭证保存在本机加密存储，不会上传。

策略介绍

这是什么策略？

在 5 分钟 K 线上，用「均线高低通道」判断多空方向，再用 CCI 交叉确认后开仓；持仓后按 ATR 分三档止盈，若趋势反向变色则平掉剩余仓。

  • 合约示例：豆一（App 默认 DCE.a2609）
  • 开仓：固定 3 手
  • 通道 N=60 · CCI(15)/均线(4)
  • 止盈：1.5 / 3 / 5 × ATR(20)，各平 1 手

1. 通道颜色怎么定？

上轨 = 最高价均线，下轨 = 最低价均线。收盘价在上轨之上→红色（偏多）；在下轨之下→绿色（偏空）；在通道内→颜色保持不变。

变色必须收盘从一侧穿到另一侧（红↔绿），通道内不算变色。

2. 开仓：先变色，再等 CCI

模式 color_then_cci：通道先变色，之后在同色期间出现 CCI 金叉/死叉，才开仓。

判定用该 5 分钟 收盘价。变色后若还没等到 CCI 又反向变色，则取消原方向等待。

3. 出场：ATR 三档 + 反向变色

开仓后两套规则并行，谁先到谁执行。

空单对称：目标在开仓价下方；反向清仓条件为通道变红。

4. App 怎么用？

  1. 看 K 线旁的「开多 / 开空」标记与条件单卡片价格。
  2. 在期货软件按卡片设置条件单（开仓 / 三档止盈 / 止损）。
  3. 右侧栏显示开仓、止盈、止损价位，不挡主图。
  4. 可在「设置」打开开仓信号声音与通知提醒。

本 App 只做盘面辅助与提醒，不会自动下单。回测表现不保证实盘收益。
