## 0. 核心思想

- 交易是概率游戏；单次无法预测，靠**盈亏比**建立长期正期望。
- **看大做小**：大周期通道定方向，小周期精准入场。
- **ATR 动态止盈**；大小周期趋势背离则止损离场。
- 唯一趋势工具：**均线高低通道**（不是收盘价均线）。

---

## 1. 均线高低通道（已明确）

通道由两根均线组成：

| 轨 | 计算 | 含义 |
|----|------|------|
| 上轨 | `MA(High, N)` | 阶段性压力 |
| 下轨 | `MA(Low, N)` | 阶段性支撑 |

| 周期 | 默认 N | 说明 |
|------|--------|------|
| **5 分钟** | **144** | 做小入场通道 |
| **60 分钟** | **60** | 看大过滤通道 |

代码位置：`pc/src/config.py` 的 `CHANNEL_N`，回测时可覆盖。

## 2. 趋势定义（概念明确，量化边界待定）

### 多头形成

- 价格站稳通道**上轨之上**
- 回调依托**下轨**获得支撑
- 连续走出新高 / 次新高
- 通道开口持续拓宽

### 空头形成

- 价格运行在通道**下轨之下**
- 反弹触碰上轨承压回落
- 不断刷新新低 / 次新低
- 通道向下扩张

### 无趋势震荡

- 通道持续收窄
- 价格反复穿插上下轨
- 高低点交错

### 趋势结束 / 反转

- **多转空**：有效跌破下轨 → 反弹触碰上轨承压 → 无法重新站稳上轨
- **空转多**：有效突破上轨 → 回踩下轨获支撑 → 不再创新低

`[待确认]` 「站稳 / 有效突破」用几根 K 线确认？收盘价还是影线？

## 3. 看大做小（PDF 操作要点）

1. **看大**：看 **60 分钟**趋势（通道 `N=60`，可配）
2. **做小**：**5 分钟**级别通道「变色」入场（通道 `N=144`，可配）
3. **禁止同色再开仓**：`[以后再定]` 大趋势为红时，5 分钟红消失后再出红，不可再开（PDF 有写，实现阶段再拍板细节）
4. **CCI 配合开仓**（已明确参数，组合方式待遍历）

### CCI（已明确参数）

| 项 | 设定 |
|----|------|
| 周期 | CCI = **15** |
| 信号线 | CCI 的 **SMA(4)** |
| 计算周期 | **5 分钟** |
| 典型用法 | CCI 与其 4 周期均线的金叉 / 死叉 |

### CCI 与通道如何组合（待回测遍历）

实盘组合尚未定死，用代码枚举对比绩效后再选定。候选模式（均可开/关）：

| 模式 ID | 开多条件（示意） | 开空条件（示意） |
|---------|------------------|------------------|
| `color_only` | 5m 变红（+60m 过滤） | 5m 变绿（+60m 过滤） |
| `cci_cross_only` | CCI 上穿 SMA4 | CCI 下穿 SMA4 |
| `color_and_cci_cross` | 5m 变红 **且** CCI 金叉 | 5m 变绿 **且** CCI 死叉 |
| `color_then_cci` | 5m 已红后，等 CCI 金叉 | 5m 已绿后，等 CCI 死叉 |
| `cci_then_color` | CCI 已金叉后，等 5m 变红 | CCI 已死叉后，等 5m 变绿 |
| `color_and_cci_above` | 5m 变红 **且** CCI>SMA4 | 5m 变绿 **且** CCI<SMA4 |

遍历时固定：通道参数、ATR 止盈、剩余仓 5m 反向平；只扫上表模式（及是否启用 60m 过滤、同色禁止）。

### 「通道变色」（已明确）

| 状态 | 条件 | 颜色 |
|------|------|------|
| 通道上方 | 价格在**上轨之上** | **红色**（多头色） |
| 通道下方 | 价格在**下轨之下** | **绿色**（空头色） |
| 通道内部 | 上轨与下轨之间 | **保持上一颜色**（尚未完成跨越） |

**变色** = 价格从一侧**跨过整段通道**到另一侧（红→绿 或 绿→红）。  
例如：先前在上方（红），跌破下轨进入下方 → 变绿；先前在下方（绿），突破上轨进入上方 → 变红。

判定价：**该周期 K 线收盘价**（已明确）。  
例如 5 分钟通道用这根 5 分钟线的收盘价；60 分钟通道用这根 60 分钟线的收盘价。不是盘中最高/最低触及。

## 4. 止盈 / 止损

### ATR 分批止盈（已明确）

| 项 | 设定 |
|----|------|
| ATR 周期 | **14**（可配） |
| 计算周期 | **5 分钟** |
| 目标价更新 | **滚动**：每根新 5m K 线用最新 ATR 重算目标（非开仓锁定） |
| 开仓手数 | **3 手** |
| 多头目标 | `入场价 + k × ATR` |
| 空头目标 | `入场价 - k × ATR` |
| 分批 | **3×ATR 平 1 手** → **5×ATR 平 1 手** → **7×ATR 平 1 手** |

判定同样用**该 5 分钟 K 线收盘价**是否触及目标（与通道变色一致）。

### 剩余仓位 / 「留一手」退出（已明确）

若尚未全部止盈完，剩余手数退出条件：

- **持多**：5 分钟通道**变绿**（收盘跨到下轨之下）→ 平掉剩余
- **持空**：5 分钟通道**变红**（收盘跨到上轨之上）→ 平掉剩余

即：**5m 反向变色谁先到谁平**（与分批止盈并行监控）。  
60 分钟只用于「看大」过滤开仓方向，**不作为剩余仓的平仓触发**。

> 说明：开 3 手且 3/5/7 各平 1 手时，若价格一路走到 7×ATR，三手都会止盈完毕，无剩余。  
> 「留一手在趋势」体现在：未到更高档位前继续持有，一旦 5m 反向变色则立即清掉剩余。

### 与 PDF「背离止损」的对应

PDF 中「大小周期趋势背离则止损」——当前落地为：**持仓方向与 5m 通道颜色相反即平**（5m 已变绿就平多 / 已变红就平空）。不再另设 60m 背离条件。
