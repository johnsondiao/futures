# 通道 + CCI + ATR 分批止盈 —— 交易规则定稿

> 对应回测配置：`src/config.py`  
> 样本内最优参考：豆一 `DCE.a2609`，5 分钟，固定 3 手，净盈亏约 +12,610（见 `data/goal/best_lots3.json`）  
> 图表：`data/reports/DCE_a2609_5m_chart.html`

---

## 1. 适用周期与仓位

| 项 | 设定 |
|----|------|
| 交易周期 | **5 分钟** K 线 |
| 判定价 | **该 5 分钟 K 线收盘价**（非盘中触及） |
| 开仓手数 | **3 手**（固定） |
| 合约示例 | 回测用 `DCE.a2609`；实盘按品种自行替换 |

---

## 2. 指标定义

### 2.1 均线高低通道（主趋势颜色）

| 名称 | 公式 | 当前参数 |
|------|------|----------|
| 上轨 | `MA(最高价, N)` | **N = 60** |
| 下轨 | `MA(最低价, N)` | **N = 60** |

说明：用高低价均线，不是收盘价均线。

### 2.2 通道颜色（红 / 绿）

| 状态 | 条件 | 颜色含义 |
|------|------|----------|
| 通道上方 | 收盘价 **>** 上轨 | **红色**（多头侧） |
| 通道下方 | 收盘价 **<** 下轨 | **绿色**（空头侧） |
| 通道内部 | 下轨 ≤ 收盘价 ≤ 上轨 | **保持上一根颜色**（不算变色） |

**变色**：颜色从红→绿，或绿→红（必须收盘跨过整段通道到另一侧）。

### 2.3 CCI 过滤

| 名称 | 公式 | 参数 |
|------|------|------|
| CCI | 标准商品通道指标 | 周期 **15** |
| CCI 信号线 | `MA(CCI, M)` | **M = 4** |

- **金叉**：CCI 上穿其 4 周期均线  
- **死叉**：CCI 下穿其 4 周期均线  

### 2.4 ATR（止盈用）

| 名称 | 说明 | 参数 |
|------|------|------|
| ATR | 平均真实波幅 | 周期 **14** |
| 目标更新 | **滚动**：每根新 5 分钟 K 线用**最新 ATR**重算目标价 | — |
| 止盈倍数 | **3 / 6 / 9** | 各平 1 手 |

真实波幅 TR：

```
TR = max( 当日最高-最低, |最高-昨收|, |最低-昨收| )
ATR = MA(TR, 14)
```

## 3. 开仓规则（mode = `color_then_cci`）

核心：**先通道变色，再等 CCI 交叉确认**，同向才开仓。

### 开多

1. 5 分钟通道 **变红**（由非红变为红）  
2. 变红之后、仍保持红色期间，出现 **CCI 金叉**  
3. 以该根（金叉确认收盘）开 **多头 3 手**

### 开空

1. 5 分钟通道 **变绿**  
2. 变绿之后、仍保持绿色期间，出现 **CCI 死叉**  
3. 以该根开 **空头 3 手**

### 注意

- 通道内部不改变颜色，也不产生「变色」事件。  
- 若变色后尚未等到 CCI 交叉，颜色又反向变色，则取消原方向等待，改跟新方向。  
- 「禁止同色再开」规则**暂未启用**（以后可再定）。

---

## 4. 平仓 / 止盈规则

开仓后同时监控两套出场（谁先触发谁执行）：

### 4.1 ATR 分批止盈（优先吃趋势利润）

记开仓价为 `E`，当前 ATR 为 `A`（滚动）：

| 档位 | 多头目标价 | 空头目标价 | 平仓手数 |
|------|------------|------------|----------|
| 第 1 档 | `E + 3×A` | `E - 3×A` | 1 手 |
| 第 2 档 | `E + 6×A` | `E - 6×A` | 1 手 |
| 第 3 档 | `E + 9×A` | `E - 9×A` | 1 手 |

判定：该 5 分钟 **收盘价**触及（多头收盘 ≥ 目标；空头收盘 ≤ 目标）。

### 4.2 剩余仓：反向变色即平

若尚未全部止盈完：

- **持多**时，通道 **变绿** → 市价（收盘）平掉剩余  
- **持空**时，通道 **变红** → 平掉剩余  

---

## 5. 操作流程（简图）

```
看 5m 收盘
    │
    ├─ 更新通道颜色（上红 / 下绿 / 内保持）
    │
    ├─ 若有持仓
    │     ├─ 收盘触及 ATR×3/6/9 → 分批平 1 手
    │     └─ 颜色反向变色 → 平剩余
    │
    └─ 若空仓
          ├─ 刚变红 → 等待 CCI 金叉 → 开多 3 手
          └─ 刚变绿 → 等待 CCI 死叉 → 开空 3 手
```

| 可选 | [`同花顺_副图_ATR止盈参考.txt`](./同花顺_副图_ATR止盈参考.txt) | 副图 | ATR 数值曲线（主图已含止盈横线，可不挂） |

盘面示意：

```
┌─────────────────────────────────────────────┐
│ 主图：通道红/绿                               │
│      白横线 = 开仓价（持仓期间）               │
│      红/黄/绿虚横线 = 止盈 3/6/9×ATR          │

```

**总原则**：同一根 5 分钟 **收盘** 后，主图与 CCI 副图字幕方向一致再动手；盘中未收盘不算。

### 7.2 何时开仓

三图开仓字幕条件一致（定稿：先变色，再 CCI 交叉）：

| 动作 | 主图通道 | CCI 副图 | ATR 副图 | 你怎么做 |
|------|----------|----------|----------|----------|
| **开多 3 手** | 出现 **开多** | 出现 **开多** | 出现 **开多** | 三图都写「开多」→ 开多 |
| **开空 3 手** | 出现 **开空** | 出现 **开空** | 出现 **开空** | 三图都写「开空」→ 开空 |
| 不开 | 缺任一图、或方向不一致 | — | — | 等下一根收盘再看 |

对应逻辑（字幕背后）：

```
变红 ──► 仍为红色期间 ──► CCI 金叉 ──► 三图「开多」──► 开多 3 手
变绿 ──► 仍为绿色期间 ──► CCI 死叉 ──► 三图「开空」──► 开空 3 手
```

开仓检查清单：

1. 周期是不是 **5 分钟**、刚收盘？  
2. 主图、CCI、ATR **是否同一根 K 都写了「开多」**（或都写了「开空」）？  
3. 是 → 按字面方向开 **3 手**；否 → 不动。

---

### 7.3 何时平仓

持仓后两套出场，**谁先到谁执行**；盘面仍用字幕 + ATR 虚线辅助。

#### A. ATR 分批止盈（优先）

开仓价记为 `E`，看 ATR 副图当前 ATR（图例数值）与 ×3/×6/×9 虚线：

| 档 | 持多目标 | 持空目标 | 手数 | 盘面怎么认 |
|----|----------|----------|------|------------|
| 1 | `E + 3×ATR` | `E - 3×ATR` | 平 1 手 | 收盘触及对应档；ATR 副图常出 **平多/平空** |
| 2 | `E + 6×ATR` | `E - 6×ATR` | 再平 1 手 | 同上 |
| 3 | `E + 9×ATR` | `E - 9×ATR` | 再平 1 手 | 同上 |

心算：目标价 = 开仓价 ±（图例 ATR × 3 或 6 或 9）。

#### B. 剩余仓：反向变色即平

| 持仓 | 主图变化 | 三图字幕 | 你怎么做 |
|------|----------|----------|----------|
| 持多 | 通道 **变绿** | 出现 **平多** | 平掉剩余多单 |
| 持空 | 通道 **变红** | 出现 **平空** | 平掉剩余空单 |

平仓检查清单：

1. 有持仓？  
2. **止盈**：收盘是否已到 `E±3/6/9×ATR` → 到了就平对应 1 手。  
3. **或反向**：三图是否同出「平多」或「平空」→ 是则平掉剩余。  
4. 两套同时到，按先触发的执行即可（通常先止盈档、再变色清仓）。

### 7.4 开平对照（一张图）

```
空仓时
  三图同出「开多」 ──────────────► 开多 3 手
  三图同出「开空」 ──────────────► 开空 3 手
  字幕不全 / 不一致 ─────────────► 不开

持仓时
  收盘触及 E±3×ATR ─────────────► 平 1 手
  收盘触及 E±6×ATR ─────────────► 再平 1 手
  收盘触及 E±9×ATR ─────────────► 再平 1 手
  三图同出「平多」(持多遇变绿) ──► 平剩余多
  三图同出「平空」(持空遇变红) ──► 平剩余空
```
