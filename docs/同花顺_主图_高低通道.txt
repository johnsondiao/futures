{━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━}
{ 名称：高低通道+开平仓提示（主图）              }
{ 周期：5分钟 | 用法：主图叠加                  }
{ N=60 通道  P=15/M=4 CCI  ATR=14 止盈0.5/1/1.5倍}
{                                              }
{ v13：修复FILLRGN整屏涂红（COLORLIRED不能当填充色}
{  参数）。通道只用红/绿上下两条线，不做区域填充。}
{  历史字幕只显示最近80根，避免密密麻麻。       }
{  条件单图例三行：开仓价/止盈价/止损价           }
{━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━}

N:=60;
P:=15;
M:=4;
ATRN:=14;

{ ——— 通道：红=多头两条线，绿=空头两条线（无填充） ——— }
上轨线:=MA(HIGH,N);
下轨线:=MA(LOW,N);

侧:=IF(CLOSE>上轨线,1,IF(CLOSE<下轨线,-1,0));
色值:=VALUEWHEN(侧<>0,侧);

上轨红:IF(色值>0,上轨线,DRAWNULL),COLORRED,LINETHICK2;
下轨红:IF(色值>0,下轨线,DRAWNULL),COLORRED,LINETHICK2;
上轨绿:IF(色值<0,上轨线,DRAWNULL),COLORGREEN,LINETHICK2;
下轨绿:IF(色值<0,下轨线,DRAWNULL),COLORGREEN,LINETHICK2;

变红:=色值=1 AND REF(色值,1)<>1;
变绿:=色值=-1 AND REF(色值,1)<>-1;
距变红:=BARSLAST(变红);
距变绿:=BARSLAST(变绿);

{ ——— CCI ——— }
TYP:=(HIGH+LOW+CLOSE)/3;
CCI线:=(TYP-MA(TYP,P))/(0.015*AVEDEV(TYP,P));
CCI均:=MA(CCI线,M);
金叉:=CROSS(CCI线,CCI均);
死叉:=CROSS(CCI均,CCI线);

候选多:=金叉 AND 色值=1 AND 距变红<距变绿;
候选空:=死叉 AND 色值=-1 AND 距变绿<距变红;
开多:=候选多 AND COUNT(候选多,距变红+1)=1;
开空:=候选空 AND COUNT(候选空,距变绿+1)=1;

距开多:=BARSLAST(开多);
距开空:=BARSLAST(开空);

{ ——— ATR 止盈 ——— }
TR1:=MAX(HIGH-LOW,MAX(ABS(HIGH-REF(CLOSE,1)),ABS(LOW-REF(CLOSE,1))));
ATR:=MA(TR1,ATRN);
入场价:=VALUEWHEN(开多 OR 开空,CLOSE);

目标1多:=入场价+0.5*ATR;
目标2多:=入场价+1*ATR;
目标3多:=入场价+1.5*ATR;
目标1空:=入场价-0.5*ATR;
目标2空:=入场价-1*ATR;
目标3空:=入场价-1.5*ATR;

达标1多:=EXIST(CLOSE>=目标1多,距开多+1);
达标2多:=EXIST(CLOSE>=目标2多,距开多+1);
达标3多:=EXIST(CLOSE>=目标3多,距开多+1);
达标1空:=EXIST(CLOSE<=目标1空,距开空+1);
达标2空:=EXIST(CLOSE<=目标2空,距开空+1);
达标3空:=EXIST(CLOSE<=目标3空,距开空+1);

反向平多:=变绿 AND 距开多<距开空;
反向平空:=变红 AND 距开空<距开多;
距反向平多:=BARSLAST(反向平多);
距反向平空:=BARSLAST(反向平空);

持多手数:=IF(距开多<距开空 AND 距开多<距反向平多,3-达标1多-达标2多-达标3多,0);
持空手数:=IF(距开空<距开多 AND 距开空<距反向平空,3-达标1空-达标2空-达标3空,0);

等多确认:=色值=1 AND 距变红<=距开多 AND 持多手数=0 AND 持空手数=0;
等空确认:=色值=-1 AND 距变绿<=距开空 AND 持多手数=0 AND 持空手数=0;
多头态:=等多确认 OR 持多手数>0;
空头态:=等空确认 OR 持空手数>0;

{ CCI交叉近似触发价 }
SumPrev:=SUM(REF(TYP,1),P-1);
AvedevPrev:=REF(AVEDEV(TYP,P),1);
信号线冻:=REF(CCI均,1);
触发价:=(0.015*AvedevPrev*信号线冻*P+SumPrev)/(P-1);

预估止盈1:=IF(等多确认,触发价+0.5*ATR,触发价-0.5*ATR);
下一止盈多:=IF(NOT(达标1多),目标1多,IF(NOT(达标2多),目标2多,目标3多));
下一止盈空:=IF(NOT(达标1空),目标1空,IF(NOT(达标2空),目标2空,目标3空));

{ ========== 条件单三行 ========== }
条件开仓价:IF(等多确认 OR 等空确认,触发价,DRAWNULL),COLORCYAN,LINETHICK2;
条件止盈价:IF(等多确认 OR 等空确认,预估止盈1,IF(持多手数>0,下一止盈多,IF(持空手数>0,下一止盈空,DRAWNULL))),COLORRED,DOTLINE,LINETHICK1;
条件止损价:IF(多头态,下轨线,IF(空头态,上轨线,DRAWNULL)),COLORMAGENTA,DOTLINE,LINETHICK2;

{ ——— 事件（必须仍在持仓窗口内，避免反向清仓后误标止盈） ——— }
止盈1多:=达标1多 AND NOT(REF(达标1多,1)) AND 距开多<距开空 AND 距开多<距反向平多;
止盈2多:=达标2多 AND NOT(REF(达标2多,1)) AND 距开多<距开空 AND 距开多<距反向平多;
止盈3多:=达标3多 AND NOT(REF(达标3多,1)) AND 距开多<距开空 AND 距开多<距反向平多;
止盈1空:=达标1空 AND NOT(REF(达标1空,1)) AND 距开空<距开多 AND 距开空<距反向平空;
止盈2空:=达标2空 AND NOT(REF(达标2空,1)) AND 距开空<距开多 AND 距开空<距反向平空;
止盈3空:=达标3空 AND NOT(REF(达标3空,1)) AND 距开空<距开多 AND 距开空<距反向平空;
清仓多:=反向平多;
清仓空:=反向平空;

近:=CURRBARSCOUNT<=80;

{ ========== 字幕：仅最近80根 + 最新条件单提示 ========== }
DRAWTEXT(ISLASTBAR AND 等多确认,条件开仓价,'开多 大于等于开仓价'),COLORCYAN;
DRAWTEXT(ISLASTBAR AND 等空确认,条件开仓价,'开空 小于等于开仓价'),COLORCYAN;
DRAWTEXT(ISLASTBAR AND 多头态,条件止损价,'止损看品红线'),COLORMAGENTA;
DRAWTEXT(ISLASTBAR AND 空头态,条件止损价,'止损看品红线'),COLORMAGENTA;

DRAWTEXT(开多 AND 近,LOW-1.2*ATR,'开多3手'),COLORRED;
DRAWTEXT(开空 AND 近,HIGH+1.2*ATR,'开空3手'),COLORGREEN;
DRAWTEXT(止盈1多 AND 近,HIGH+0.3*ATR,'止盈1/3'),COLORRED;
DRAWTEXT(止盈2多 AND 近,HIGH+0.3*ATR,'止盈2/3'),COLORRED;
DRAWTEXT(止盈3多 AND 近,HIGH+0.3*ATR,'止盈3/3'),COLORRED;
DRAWTEXT(清仓多 AND 近,HIGH+1.2*ATR,'反向清仓'),COLORGREEN;
DRAWTEXT(止盈1空 AND 近,LOW-0.3*ATR,'止盈1/3'),COLORGREEN;
DRAWTEXT(止盈2空 AND 近,LOW-0.3*ATR,'止盈2/3'),COLORGREEN;
DRAWTEXT(止盈3空 AND 近,LOW-0.3*ATR,'止盈3/3'),COLORGREEN;
DRAWTEXT(清仓空 AND 近,LOW-1.2*ATR,'反向清仓'),COLORRED;
