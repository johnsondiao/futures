# 60 分钟通道趋势策略（人工执行友好版）

> 状态：**新策略，已回测定参，待实盘小仓位验证**。
> 策略类与 5m 版共用 `strategies/channel_trend.py`（`ChannelCciAtrStrategy`），仅周期与参数不同。
> 正式参数定义：`src/config.py` 的 `STRATEGY_60M` / `STRATEGY_PROFILES["60m"]`。

## 1. 为什么要这个策略

5m 版策略单笔期望只有 ≈ +100 元/3 手（每吨约 3.4 元的方向优势），人工下单链路
（看到信号 → 反应 → 切软件 → 下单 → 滑点）轻易消耗掉全部边际。延迟敏感性测试
（`scripts/delay_sensitivity.py`）显示 5m 版**迟到 10 分钟即整体转负**。

60m 版单笔边际大 4~5 倍，下单反应窗口按小时计，适合人工执行。

## 2. 策略规则

| 项 | 设定 |
|----|------|
| 周期 | **60 分钟** K 线（信号在 K 线收盘确认后产生） |
| 合约 | DCE.a2609（可扩展） |
| 通道 | 上轨 = MA(High, **60**)，下轨 = MA(Low, **60**) |
| 变色 | 收盘跨上轨之上 → 红；跨下轨之下 → 绿；通道内保持原色 |
| 入场 | `color_then_cci`：变色后，等 **CCI(15) 上穿/下穿 SMA(3)** 确认再开仓 |
| 手数 | 固定 **3 手** |
| 止盈 | **0.8 / 1.5 / 2.5 × ATR(20)** 三档各平 1 手，ATR 滚动（每根 K 线用最新 ATR 重算目标） |
| 剩余仓 | 60m 通道**反向变色**（收盘）即平掉剩余 |
| 止损 | 无硬止损，由反向变色兜底 |

回测运行：

```
python scripts/run_backtest.py --period 60m
```

## 3. 定参依据（DCE.a2609 60m，2025-09-12 ~ 2026-08-12，1523 根）

### 寻优方法（`scripts/search_60m.py`）

3 入场模式 × 6 通道 × 5 CCI 周期 × 3 信号线 × 10 止盈组 = 2700 组网格；
按「入场逻辑」分组，要求组内（不同 ATR 退出变体）**全部盈利**才算稳健区：
90 个样本足够的入场逻辑组中 55 组满足，且 Top 全部是
`color_then_cci + 通道 60`——与 5m 版同一入场家族，参数邻域平坦（非尖峰）。

### 选定参数样本内表现

- 29 笔，胜率 **72%**（21 胜 8 负），净利 **+15,972 元**，平均 **+551 元/笔**
- 组内 10 种 ATR 退出变体全部盈利（pnl 区间 +10,036 ~ +15,972）

### 执行宽容度（延迟敏感性，含 1 元/吨滑点）

| 场景 | 净盈亏 |
|------|-------:|
| 信号收盘即下单 | +15,972 |
| 仅滑点 2 元 | +13,027 |
| **迟 1 根（1 小时）** | **+11,634** |
| **迟 2 根（2 小时）** | **+8,819** |
| 迟 3 根（3 小时） | +3,902 |
| 迟 6 根（6 小时） | +385 |

结论：**1~2 小时内下单仍保持大部分期望；超过 3 小时不建议追**。

## 4. 执行纪律（实盘）

1. 信号以 60m K 线**收盘**为准（App 推送即收盘确认）。
2. 收到信号后尽快市价下单；若距信号超过 3 根 K 线（3 小时），放弃该笔。
3. 下单后立即按卡片挂三档止盈条件单（0.8/1.5/2.5 × 当时 ATR）；
   反向变色信号出现时手动平掉剩余。
4. 单笔 3 手不变；不加杠杆摊本。

## 5. 已知局限

- 样本为单一合约约 11 个月（a2609 合约上市以来的全部 60m 数据），
  未跨合约/跨品种验证；先小仓位实盘对照。
- 小节末尾桶（14:00–15:00、22:00–23:00）的信号要等下一交易时段首根 K 线到达才确认，
  收盘前一刻的信号可能延迟数小时才提醒（整点聚合 + 收盘确认的固有特性，前后端一致）。
- 无硬止损：单笔最大亏损取决于反向变色时机，极端行情下单笔浮亏会明显大于 5m 版。
- 信号频率低（约每月 2~3 笔），需要耐心。

## 6. 与 5m 版的关系

两版并存于 `STRATEGY_PROFILES`。5m 版继续保留（适合程序化/条件单即时执行场景）；
人工手动交易建议使用 60m 版。

## 7. 安卓 App 支持

App 设置页顶部有「策略选择」（5 分钟 / 60 分钟），选择会持久化记住；
盘面、条件单卡片、开仓提醒与飞书推送都跟随所选策略。
App 内部把 5m 行情按整点聚合成 60m K 线（已验证与天勤 60m K 线逐根一致），
信号仅在 60m 收盘确认后触发；飞书推送附带参考开仓价与三档止盈价。
